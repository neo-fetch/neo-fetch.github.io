Draw Your Agents: A Visual AI Agent Builder That Runs Entirely in Your Browser

By Mayank Deshpande · 08 Jun 2026

Draw Your Agents is a visual, drag-and-drop AI agent builder. You sketch an agent workflow on a canvas -- nodes, prompts, and connections -- and it compiles into a complete, runnable Python project targeting Google ADK (Agent Development Kit) or LangGraph. Pick your framework; the same diagram generates idiomatic code for either. No boilerplate, no framework wrangling, no code to write by hand.

The part I am most proud of: it runs entirely in your browser. It is a static page by design, so your prompts, schemas, and generated code never leave your machine -- there is no server, no sign-up, and nothing to install. Open the link, start drawing, and download a ready-to-run .zip.

From Diagram to Deployable Agent in Three Steps

No more staring at a blank main.py. Building a multi-agent workflow comes down to three things you can do in minutes.

1. Draw

Drag agents, functions, routers, and loops from the palette onto the canvas. Rename anything in place -- references update automatically.

2. Wire

Connect nodes to define data flow, and drag schema fields straight into prompts as typed variable chips. A live validity pill tells you the instant the graph is sound.

3. Download

Pick your target -- ADK or LangGraph -- and watch the Python update live as you edit, then export a runnable .zip. pip install && python -m workflow and you are live.

What Makes It Different

Two Frameworks, One Diagram

The same canvas compiles to Google ADK or LangGraph -- flip a target switch and the generator emits idiomatic code for either: ADK's positional Event piping and Workflow graphs, or LangGraph's shared TypedDict state and StateGraph wiring. Draw once, ship to whichever stack you prefer.

Drag-and-Drop Canvas

A real node-graph editor (powered by React Flow) with editable node names, free arrangement, and a distinctive "drafting table" blueprint UI that color-codes every node type.

Variable Chips in Prompts

Drag a schema field into an agent's prompt and it becomes a typed chip -- <Schema.field from node> -- that auto-wires the agent's input. No more copy-pasting variable names and hoping they match.

Live Code Preview

The generated Python project -- ADK or LangGraph -- recompiles on every edit, right in the browser. You always see exactly what you are shipping -- and validation findings surface inline before you export.

Self-Correcting Loop Node

Drop in a critic/reviser loop node -- a contained generate → critique → revise cycle that iterates until an LLM critic approves. It compiles to a real ADK orchestrator behind a single tidy node.

The Look: Named After Bathory

The tool's dark, vellum-and-ink theme is named after Bathory -- the pioneering Swedish black-metal band Quorthon started in the 1980s. The aesthetic is a deliberate homage, not decoration.

A Palette Lifted From Record Sleeves

The colors descend from the base16 "Black Metal (Bathory)" scheme by metalelf0, whose tones evoke late-1980s extreme-metal cover art: pure-black paper, ash-grey lettering, a cold teal, and one burnt-orange ember.

Anti-Commercial by Design

Sharp corners, film grain, and CRT scanlines -- a pointed rejection of the neon, "vibrant", gamer-centric look of modern UI. The drafting-table blueprint grid is meant to feel made, not marketed.

The aesthetic carries the ethos
The band's principles -- independence, skepticism of dogma, anti-war, and zero tolerance for hate -- are the same ones this project stands for. That stance is exactly why the tool is browser-only and free: no server, no accounts, no commercial lock-in, and you own the code you generate.

A Peek Under the Hood

You do not need to know any of this to use the tool -- but it is the foundation that keeps the generated code trustworthy.

One Graph IR, the Single Source of Truth

Every input -- your canvas edits today, draw.io diagrams tomorrow -- compiles down to one versioned JSON Graph IR. Validation, save/load, and both code generators (ADK and LangGraph) all operate on that single IR, never on raw UI state. It is the keystone the whole tool is built around.

TypeScript Codegen, Golden-File Tested

The IR runs through an edges compiler and per-node template fragments -- then import deduplication and Black formatting -- to assemble a real multi-module project. For ADK that's workflow.py, agents.py, functions.py, schemas.py, and more; for LangGraph it's graph.py, state.py, nodes.py, and a dry-run import check. Every generated project is pinned by golden-file tests and proven to construct against google-adk==2.0.0 and langgraph 1.x.

Typed, Nested Pydantic Schemas

Define schemas in the UI and nest them (customer: Customer); the validator rejects cycles and the generator emits the Pydantic models in dependency order. Data flow between agents is typed end to end.
